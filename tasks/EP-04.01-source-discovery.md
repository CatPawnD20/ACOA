# EP-04.01 — Authorized source discovery and immutable provenance

Trace: F-02.01/F-02.05/F-02.06; E-05/E-06/E-07; P-07; X-07;
ADR-002/005/006/013.

## Scope and behavior

The discovery boundary supports explicit official API, search API and public HTTP
source classes. Each source policy records exact hosts, media types, shared data
categories, access terms, license reference, validity window, response/redirect/result
bounds and snapshot lifetime. A separate trusted access permit must bind the same
source and policy version, must not predate that policy, and must be current when an
operation starts. A typed object or digest alone is never authority.

`DiscoveryService` applies those rules before invoking an injected resolver or
transport. URLs require HTTPS and an exact allowlisted canonical host, and reject
credentials, query strings, fragments, non-default ports and direct IP literals. DNS
must return only distinct globally routable addresses. The transport contract requires
connections to those pinned addresses with automatic redirects disabled; every redirect
is resolved and checked again within the policy hop limit. Query data is passed
separately and persisted only as a digest, so URL credentials and query tokens cannot
enter provenance records.

Resources receive a deterministic source-local identity from source ID, resource kind
and the adapter's stable external key. Changing only the URL therefore does not create
a second resource. Cross-source organization/opportunity normalization and broader
deduplication remain EP-04.02–04.04 work.

Successful fetches validate the base media type, declared and actual byte lengths, and
the response bound. Snapshot expiry is the earliest of source TTL, source-policy expiry
and permit expiry. Access evidence binds the source policy, access-decision identity and
validity window, and the complete DNS/redirect hop chain. Returned bytes are wrapped as
`UntrustedSourceDocument`; web content never becomes a command or authorization source.
Timeout, unavailable, access challenge, not-found, blocked and malformed responses remain
explicit non-success observations.

## Persistence

Revision `0010_source_discovery` adds immutable PostgreSQL records for source policies,
discovery batches, snapshot metadata and access observations. Application access is
read/insert only. Repository writes are exact-idempotent and reject an existing identity
with different policy, provenance, content or result data. Fetched bodies are not stored
in PostgreSQL; snapshots retain canonical URL, content digest, byte length, media type,
observation/expiry times and access evidence.

## Observed local verification

- A transient fake resolver/transport probe performed no network access. It exercised
  current and stale policy/permit bindings, deterministic canonical resource identity,
  source provenance, private-address rejection, DNS timeout, transport unavailability,
  content-type/size/declared-length bounds and successful discovery/fetch behavior.
- Alembic reported one head at `0010_source_discovery`; the retained dedicated PostgreSQL
  volume migrated from `0009_match_assessment_grants` and remained healthy.
- A transient application-role transaction inserted one source policy, one batch, one
  snapshot and two observations. Exact repeats were idempotent, a conflicting policy was
  rejected, direct `UPDATE` was denied, and the synthetic transaction was rolled back.
- The temporary host port was removed after verification. PostgreSQL returned to the
  internal base Compose network with no published host port.
- Existing tests, full lint/format/type checks, migration graph/offline SQL and package
  consistency were run without adding or changing tests, fixtures, mocks or test helpers.

## Remaining boundaries

The production integration now includes a credential-free Arbeitnow adapter with public-DNS
validation, address-pinned TLS, hostname verification, disabled automatic redirects, bounded
responses, bounded pagination and local query filtering. Its finite reviewed policy and a
successful live discovery/fetch observation are recorded in the local source-provenance store.
The adapter sends only a page number to the provider; the user's query remains local.

This task does not normalize organizations or opportunities, choose an alternate source,
bypass access controls, call a model, submit an application or send a message. Arbeitnow access
must stop when the finite policy expires until its terms and policy are reviewed again.
