# EP-08.01 — Browser adapter contract and safe form preparation

## Scope and requirement links

This task implements the framework-independent Playwright adapter boundary for
`F-08.01`, `F-08.03`, `F-08.04`, `F-08.07`, `E-03`, `E-07`, `E-10`, `P-06`, `P-07`,
`P-19`, `ADR-005`, `ADR-006` and `ADR-012`. It performs no network access, browser
launch, account login, external upload or form submission.

## Delivered behavior

- `BrowserPermit` binds one task and application to one canonical public HTTPS DNS
  origin, an expiry and explicit visit/read/fill/upload/prepare capabilities. HTTP,
  credentials in URLs, paths in authority origins, localhost and IP-literal authority
  targets fail closed. Observations must retain the exact permit and origin.
- The adapter port lets a future Playwright implementation inspect a form, fill draft
  values and upload a document. It deliberately exposes no `submit` operation, so a
  browser worker cannot bypass the central Policy Gate and External Action Executor.
- Form observations use opaque UUID field handles rather than executable selectors.
  Each field has an explicit kind, semantic purpose, required state and optional file
  media-type allowlist. Page content is represented by a digest; raw HTML is not placed
  in the domain contract.
- CAPTCHA, MFA, authentication requirements and access denial deterministically produce
  an access-challenge handoff. Required fields with unknown or unsupported purpose and
  missing verified values produce field-specific handoffs rather than guessed answers.
- Draft filling binds every supplied value to the observed field purpose and verifies
  its exact content digest. File fields and unknown purposes cannot enter this text-fill
  path.
- Resume upload re-reads the immutable storage object and requires exact artifact ID,
  version, application, resume kind, storage key, media type, content hash and size. It
  accepts only the exact observed resume file field and verifies the adapter receipt
  against the same operation. Raw artifact bytes and field values are excluded from
  object representations.

## Verification

Verified locally on 2026-10-16 with an in-memory transient adapter:

- Exact-origin inspection, a digest-bound email draft and a storage-reloaded PDF resume
  upload completed through the contract without browser or network access.
- An unknown required field and CAPTCHA each produced the intended user handoff.
  Insecure HTTP and an IP-literal origin were rejected.
- The final gate covers 98 existing tests, Ruff lint/formatting, strict mypy, dependency
  consistency, approved-document preservation and the 187-file active checksum
  manifest. No test, fixture, mock or testing utility was added or modified.

## Remaining boundaries

EP-08.02 owns the isolated browser-worker process/container, Playwright runtime,
network/redirect enforcement, file mount restrictions and task-scoped credentials.
EP-08.03 owns authorized account creation, while EP-08.04 owns a synthetic test site and
submission timeout/reconciliation behavior. A returned handoff is a typed decision; its
durable scheduling and notification reuse the existing task/user-wait boundaries.
