# EP-09.02 — Fixed-scope experiment comparison and reversible selection

## Scope and requirement links

This task implements controlled baseline/candidate comparison for `E-01.07`, `E-09.04`,
`E-09.05`, `E-09.06`, `E-09.07`, `E-12.03`, `E-12.06`, `P-13`, `S-31` and
`ADR-015`. It does not activate real rollout or mutate a production strategy.

## Delivered behavior

- Baseline and candidate metrics bind exact strategy, dataset version/hash, cohort,
  sample count, successes, critical unauthorized/duplicate action counts, cost, currency
  and measurement time.
- Comparisons require the experiment's exact baseline/candidate versions. Promotion is
  possible only on the same immutable dataset, cohort, sample size and currency after
  the minimum sample count and configured absolute improvement gate are met.
- Any unauthorized-action or duplicate-external-action regression vetoes promotion and
  selects rollback regardless of quality or cost. Fixed-scope mismatch and insufficient
  samples also fail closed to the baseline.
- A successful comparison emits an immutable `promote_candidate` selection that retains
  the baseline version as its explicit restore target. Below-gate results keep the
  baseline. Selections are audit decisions and do not bypass rollout activation.
- Migration `0024_experiment_comparisons` stores append-only comparisons and exactly one
  selection per comparison. The application role cannot update or delete this history.

## Verification

Verified locally on 2026-10-16 with synthetic replay records:

- A candidate improving success rate from 50% to 70% passed a 10-point absolute gate;
  an equal candidate kept the baseline.
- One unauthorized action and a changed dataset hash each forced rollback to baseline.
- Migration graph/offline SQL reached `0024_experiment_comparisons`; the development
  database was migrated to that head.
- A rollback-only real `acoa_app` probe idempotently round-tripped comparison/selection
  records and confirmed direct update/delete denial. No synthetic rows remained.
- The final gate covers the existing test suite, Ruff formatting/linting, strict mypy,
  dependency consistency, approved-document preservation and the active checksum
  manifest. No test, fixture, mock or testing utility was added or modified.
