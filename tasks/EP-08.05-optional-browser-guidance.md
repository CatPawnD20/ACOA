# EP-08.05 — Optional advisory browser guidance

## Scope and requirement links

This task records and enforces the optional AI-browser decision for `F-08.01`,
`F-08.03`, `F-08.04`, `F-08.07`, `E-01`, `E-02`, `E-07`, `E-10.01`, `E-10.03`,
`P-06`, `P-07`, `P-17`, `ADR-005`, `ADR-006`, `ADR-007`, `ADR-012` and
`ADR-015`. Browser Use is not required by the approved architecture.

## Decision and delivered behavior

- Deterministic inspection remains the default and is selected whenever it is adequate.
  CAPTCHA, authentication and access obstacles always select user handoff.
- AI guidance is eligible only when deterministic interpretation cannot resolve a
  required non-file text field and a separately enabled, current policy with a bounded
  confidence floor exists. Disabled or expired guidance selects user handoff.
- Guidance accepts only a versioned `StructuredModelOutput`, the result type produced by
  the central Model Gateway. Its JSON must bind the exact observation ID and page digest
  and contain only field ID, semantic purpose and decimal confidence.
- Suggestions may target only unresolved required text fields. File fields, resume
  upload, unknown/other purposes, duplicate fields, low-confidence output, extra keys,
  selectors and action/tool instructions fail closed.
- `BrowserFieldSuggestion` is deliberately distinct from `BrowserField` and
  `BrowserFieldValue`. Parsing a suggestion does not mutate the trusted observation and
  grants no visit, fill, upload or submit capability. Existing deterministic guards
  continue to reject filling an observed unknown field.
- No active AI browser provider is configured. The current controlled Playwright forms
  are deterministically adequate, and production quality/cost thresholds are unset, so
  enabling live AI guidance would add risk without measured benefit.

## Verification

Verified locally on 2026-10-16 with synthetic records:

- An unresolved required text field selected advisory AI guidance only under a current
  enabled policy; deterministic adequacy took priority and a disabled policy handed off.
- A CAPTCHA observation handed off even while AI guidance was enabled.
- Exact, high-confidence field guidance parsed successfully. Attempts to target a resume
  file field or add a `tool_call: submit` key were rejected.
- The final repository gate covers the existing test suite, Ruff formatting/linting,
  strict mypy, dependency consistency, approved-document preservation and the active
  checksum manifest. No test, fixture, mock or testing utility was added or modified.

## Remaining boundaries

Live model providers, a production AI-browser SDK and quality thresholds remain
unconfigured. Future activation requires measured benefit, central Model Gateway
routing, provider data permission, browser-worker isolation and the existing Policy
Gate/External Action Executor for every external effect.
