# EP-04.03 — Risk-based employer verification and company opt-out

## Scope and requirement links

This task implements deterministic employer risk verification, fake-career-portal
signals and company-wide contact controls for `F-04.01/02/04/06`, `E-06`, `E-07.05`,
`P-08`, `P-16`, `S-08`, `S-26`, `S-34` and `ADR-005/006`. It consumes the sourced
organizations and public corporate channels from EP-04.02. It does not fetch a real
site, infer a person, send a message or authorize an external action.

## Delivered behavior

- `domain.verification` defines immutable source-bound signals, basic/deep assessment
  depth, deterministic `low/elevated/high/critical` risk, safe verification statuses,
  and company contact-control events. A basic suspicious result requires deeper
  research. Persistent important suspicion after deep research requires user review;
  critical payment or deceptive-identity evidence blocks the employer.
- `application.verification` validates current evidence and binds portal findings to an
  exact career-channel content hash. A career portal satisfies company/channel trust
  only when a current low-risk verification includes an official-site link for that
  exact portal version and no active adverse portal signal.
- Company contact blocks are projected from complete, ordered events. Employer and user
  controls are independent: only the actor that created a block can retract it, so a
  user event cannot clear an employer opt-out. Employer retraction requires newer,
  distinct source evidence. An authoritative empty history projects a clear result only
  for its exact evaluation time; the Policy Gate still receives an explicit
  `OPT_OUT_CLEAR` fact.
- `VerificationRecordRepository` stores exact-repeat-idempotent verification versions
  and serializes contact-control appends with a company-scoped transaction advisory
  lock. Migration `0012_employer_verification` grants the application role only
  `SELECT` and `INSERT`; retained records cannot be updated or deleted.

## Remaining boundaries

Signal extraction from real corporate registries, DNS/TLS, pages or browser sessions is
not implemented; typed evidence is a structural contract rather than proof of trusted
ingestion. Numeric risk calibration is intentionally absent: the approved policy uses
deterministic risk classes and requires a user decision for unresolved important doubt.
Cross-source organization/opportunity deduplication and source fallback remain EP-04.04.
Real employer contact and application submission remain disabled.
