# EP-03.05 — Labeled matching quality and resource evaluation

Trace: F-05.07; E-01.07/E-02.02/E-06.07/E-09.04–05/E-12.01–07;
P-03/P-10; ADR-004/015.

## Scope and behavior

The evaluation contract binds every expected class to an example identity, exact
opportunity version and content hash, evidence identity, labeling timestamp and
comparison cohort. Candidate assessments must target the same opportunity bytes and
matching policy. The report records the label period, dataset version and canonical
dataset digest, preventing a policy result from being presented as if it came from a
different evaluation set.

Quality counts keep their denominators explicit. A labeled qualified opportunity is
recovered only by `fit`; `excluded` is a false exclusion, while `low_priority` and
`excluded` together form the broader missed-qualified count. A qualified result sent
to research stays unresolved instead of being counted as either success or a miss.
`fit` for a known non-qualified example is a false positive. Any decisive
classification for an example labeled `research_required` is an unsupported decision.
Reports expose overall and canonically ordered cohort slices without collapsing
missing or uncertain labels into favorable results.

Resource use is reported as model calls, input/output tokens and actual cost, both in
aggregate and per named processing stage. T0 usage must have zero model calls, tokens
and cost. One report uses one explicit currency; mixed currencies fail because no
exchange rate is inferred. Cost per recovered qualified result and token-per-stage
limits use recorded usage rather than estimated provider prices.

Release gates have no built-in production thresholds. A caller must supply the exact
dataset version/hash, minimum total and per-label-class counts, recall floor,
error-rate ceilings, per-stage token ceiling, unit-cost ceiling and currency. Rate comparisons
use exact rational arithmetic, and unit cost uses multiplication rather than rounded
division. A missing quality denominator, mismatched dataset/currency or zero recovered
qualified result produces a structured failure rather than an optimistic pass.

## Observed local verification

- Existing test, lint and strict type-check baselines were run without adding or
  changing tests, fixtures, mocks or testing utilities. Focused behavior checks used
  transient synthetic objects only.
- Eight synthetic labels covered qualified, non-qualified and research-required
  expectations across two cohorts and T0/T1 stages. The report produced one recovered
  qualified result, two missed qualified results including one false exclusion, one
  unresolved qualified result, one false positive and one unsupported decisive result.
- T0 reported zero calls/tokens/cost. T1 totals rolled up exactly into the overall
  counts and costs; mixed currencies were rejected.
- Dataset hashing was invariant to input order. A gate at exact rate and cost
  boundaries passed under Decimal precisions 6, 28 and 50; stricter quality, token and
  cost limits failed with structured reasons. A different dataset digest also failed.

## Remaining boundaries

The synthetic labels prove the evaluation machinery, not matching quality in real
use. No human-verified or production opportunity set is present, so L2 `D-08`/`D-12`
numeric limits remain TBD and no production threshold has been calibrated or approved.
The evidence UUID is a binding reference, not authentication of a label source.
Persistent experiment runs, trusted label ingestion and strategy promotion belong to
later work. This task performs no model/provider call, database write, application,
message or other external action. Hosted CI has not run because no remote repository
exists.
