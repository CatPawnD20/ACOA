# EP-09.01 — Bounded strategy experiment controls and rollback

## Scope and requirement links

This task implements strategy hypothesis, cohort, limit, measurement and rollback
contracts for `E-03.05`, `E-09.01`, `E-09.03`, `E-09.07`, `E-12.03`, `E-12.06`,
`P-13`, `S-31`, `ADR-012` and `ADR-015`. It does not implement A/B promotion,
generated code, a live rollout or any new external-action authority.

## Delivered behavior

- An immutable experiment plan binds one hypothesis and cohort to baseline/candidate
  strategy versions, one success metric, sample/case limits, external-impact and cost
  ceilings, rollback floor, expiry and exact user-goal, authorization and hard-constraint
  hashes.
- Replay and limited-real modes are distinct. Replay requires zero external impact.
  Because the approved real impact ceiling remains `TBD`, this package enables replay
  records only and does not configure or start real rollout.
- Append-only checkpoints retain ordered case counts, external impact, metric numerator
  and denominator, actual cost and the current immutable bindings. They distinguish
  running, comparison-ready, stopped, rolled-back and promoted states without rewriting
  history.
- Deterministic assessment returns rollback to the baseline strategy when goal,
  authorization or hard constraints change; expiry, case, external-impact or cost bounds
  are exceeded; currency differs; or the measured result falls below the rollback floor.
  Meeting the minimum sample returns only `ready_for_comparison`; EP-09.02 owns comparison
  and promotion.
- Migration `0023_strategy_experiments` stores immutable plans and checkpoints. The
  application role has read/insert access and cannot update or delete either history.

disabled until the user resolves `experiments.max_external_impact` and the rollout gate.
