## Environment adjustments

The system Python launcher found no registered interpreter. A project environment was created from Codex's bundled Python without changing system Python.

The first virtual-environment bootstrap failed because the sandbox's default temporary directory was not writable. Redirecting shell-local TEMP/TMP to `.tmp` allowed the ordinary environment setup.

The initially selected mypy 2.4.0 wheel was rejected by Windows Application Control when loading a native DLL. Mypy 1.18.2 from its official source distribution provided a pure Python implementation compatible with this environment. No security policy or DLL trust setting was changed. The unused native dependencies from the initial attempt were uninstalled from the project environment. The final clean installation confirms the narrower toolchain works without them.

## Security and remaining scope

Only synthetic inputs were used. No real `.env`, credentials, OAuth tokens, CVs, mail contents, employer endpoints, or browser sessions were accessed or introduced. Staging is restricted to project documentation and bootstrap files; environment/cache directories are excluded. `.gitignore` is a safeguard, not a claim that force-adding a secret is impossible.

Approved L0–L4 hashes and archived original-file hashes are checked against the pre-cleanup baseline before delivery. Internal historical approval/reference wording remains documented in the specification index; approved document text was not rewritten.

No application settings model was implemented. `dry_run=true` and `external_actions_enabled=false` remain binding requirements for EP-00.02 and later activation; this bootstrap contains no action entry point to enable. No job search, database, model, email, browser, dashboard, account, CI, or deployment feature was implemented or tested. EP-00.01 completion is not full EP-00 G0/S0 acceptance.

Direct tool versions are pinned; transitive development dependencies are not fully locked. The current checks are local Windows/Python 3.12 checks, not CI or cross-platform results.
