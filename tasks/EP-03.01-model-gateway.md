# EP-03.01 — Offline structured Model Gateway and shared resource budget

## Scope and acceptance

Trace: E-01/E-02/E-06; P-03/P-10/P-17; ADR-004/015. Add structured model request,
limits and response envelopes, offline provider protocol, durable fenced calls,
task token/time accounting and a shared monetary reservation ledger. Exercise the
gateway with in-memory fake providers. No new SDK, dependency, real model API,
credential discovery, employer action or user data is introduced. Live mode is
unavailable; requests/responses must explicitly remain simulations.

## Flow and boundaries

The caller supplies a current running task's exact owner/lease token, model alias,
prompt/schema versions and explicit input/output token, timeout, currency and cost
bounds. No costs or limits are inferred from a missing field. The existing safe
authority starts with no budget/timezone, so calls are blocked until trusted
configuration is supplied. Offline calls need no employer sending grant and do
not enable external actions. Only trusted composition may register a local fake;
arbitrary Python callbacks are not a security boundary or proof of no network I/O.
No real adapter is included or registered by repository code.

The PostgreSQL implementation locks current authority, task and prior call identity,
then reserves resources and commits a unique running fence before the callback.
Repeated/concurrent calls cannot get another fence. Aggregate task token/time
usage includes consumed values and outstanding unknown holds. The shared
`budget_ledger` now references a typed `resource_attempts` registry for both model
and external attempts; existing monetary usage queries therefore account for both.
`0005_model_gateway` backfills existing external budget identities before replacing
the FK, without deleting rows. The actual development ledger was empty at upgrade;
nonempty historical backfill was inspected, not runtime-replayed on retained data.

`0006_resource_target_guard` explicitly requires a nonnull selected target FK:
SQL CHECK equality alone can evaluate unknown for NULL. The follow-up preserves
the already applied revision rather than rewriting it. Both missing-target kinds
were runtime-rejected; valid model and external resource paths were exercised.

The gateway matches response call/provider/request/model/prompt/schema identity.
The structured payload must be a JSON object with no nonfinite literals, duplicate
keys or invalid UTF-8; numeric parsing uses Decimal. This is envelope/JSON validation,
not feature-specific schema/semantic quality approval. Those validators and routing
belong to EP-03.02/03.04. Every output remains untrusted data, never permission or
a verified profile claim. Simulation usage is not a measurement of real models,
prices, tokens or invoices.

Known valid usage settles exact cost, records both token directions and releases
unused holds. Invalid/foreign/missing responses and expired/crashed calls remain
unknown with money/token/time held; no automatic provider retry occurs. Reported
token, cost or elapsed-time overruns are stored honestly, reject the output and
pause current authority. Callback deadlines/limits remain a trusted adapter
contract; this synchronous gateway does not forcibly interrupt arbitrary Python.
Actual SDK limits and OS isolation are later release gates.

Trace metadata uses an explicit allowlist; adding a future private request field
cannot automatically persist it. Raw prompts, output bodies and task lease fences
are not traced. Only hashes, versions, operation/provider IDs, limits, simulated
status and measured usage persist. Output bodies return to the caller only on
success; repeated calls do not reload a private output or run it again. Protected
artifact/cache persistence remains its later owner.

## Policy v2 monetary arithmetic correction

Shared-budget review found that ambient Decimal precision could round a tiny
addition away at a hard cap. `check_decimal_limit` uses a local upward-rounded
bound: it permits only proven headroom, rejects a proven overrun, and reports
indeterminate precision as `budget_precision_unknown`/RECHECK. Task seconds use
the same conservative check; task token totals use exact integers. Measured
nanoseconds are constructed directly as Decimal seconds without rounded division.

Policy is now `acoa-policy/2` because evaluated decisions changed. An old-policy
grant requires a newly approved current-policy version; it is not upgraded
silently. No active real grant existed or was modified. Binding P-10 limits and
the approved documents are unchanged; this enforces their existing hard-cap rule.
