# EP-10.05 follow-up — Explicit zero-data pilot scope

## Scope and requirement links

This follow-up supports the approved controlled self-send pilot under `P-17`, `E-07`,
`ADR-006` and `ADR-011`. It does not add a data category, enable an external action or
send a message.

## Delivered behavior

- Privacy configuration distinguishes an enabled, nonempty bounded data allowlist from
  an explicitly disabled data-sharing mode.
- Disabled data sharing requires the configured allowlist and grant data scope to remain
  empty. Contradictory values fail readiness.
- Existing configurations remain compatible because the new flag defaults to enabled and
  therefore retains the prior nonempty-allowlist requirement.
- The approved pilot can carry a synthetic boundary-test message with no profile, CV,
  attachment, employer or sensitive data.

## Verification

Local verification covers valid zero-data settings, contradictory disabled scopes,
existing tests, Ruff, strict mypy, migration graph/offline SQL and the active checksum
manifest. No test, fixture, mock or testing utility was added or modified.
