# EP-01.04 — Versioned policy decision records

## Scope and acceptance

Trace: EP-01.04; E-07; P-11/P-17; ADR-006/007/014. Produce structured JSON with
`decision_id`, `policy_version`, decision, permission mode and closed reason codes.
Bind the result to the exact request and complete trusted evaluation snapshot.
Changing a target, grant/consent, setting, evidence state, usage, artifact, purpose
or evaluation time requires a new evaluation. No provider or persistence adapter
is introduced here; PostgreSQL persistence belongs to EP-02.

## Design and trust boundary

The orchestration evaluates policy itself instead of accepting a caller's ALLOW.
The caller supplies an audit UUID; no clock, random generator, network, environment
or file access occurs inside evaluation. Complete dataclass snapshot hashing also
covers newly added context fields. Decimal spelling and tuple ordering can cause
conservative rechecks; no lossy numeric normalization is applied. Timestamps are
normalized to UTC. Policy changes require a new policy version and matrix review;
the existing gate remains `acoa-policy/1` because this task adds tracing only.

JSON contains opaque hashes and the audit UUID, never raw account addresses,
profile content, recipients or grant/consent bodies. Hashing is not encryption:
records still require access controls and must not be published. The transient
private snapshot is hashed locally and must not be logged. Hashes and typed records
are not signatures or authenticated authorization. A record cannot authorize an
external action, bypass the executor or establish that a snapshot is authoritative.
`record_matches_evaluation` checks exact input and recomputed result consistency;
the future database/executor must resolve current authority and reserve atomically.

## Verification

On 2026-10-15, direct synthetic runtime checks passed for a fully authorized
preflight record, deterministic repeat evaluation, JSON schema fields, absence of
raw account/grant bodies, immutable records, every action kind, and fixed forbidden
actions. Changed clock/snapshot, pause, safe mode, revoked grant, quota, budget,
evidence, artifact, purpose, account, recipient, policy version and fabricated
result invalidated prior records. Equivalent UTC instants produced equal hashes.
All 98 existing tests, Ruff lint/format and strict mypy passed. No tests, fixtures,
real personal data or live integrations were added. Persistence and atomic
execution are not claimed by this task.
